# Revision Record for the Guanyin Lingqian Texts

[中文](校订记录.md) | **English**

The 100 stick texts in `index.html` (repository root) were scraped from the sources below on 2026-11-16, compared character by character and then compiled. This file records which sources were used, the rules for choosing between variants, and what was changed.

## Sources

This is the most widely circulated mainland-Chinese edition of the Guanyin Lingqian: stick 1 is "钟离成道", and each stick has a rank (吉凶), a palace (宫位), a story title (典故), a four-line poem (诗曰), its meaning (诗意) and an interpretation (解曰). It is a different text from the "Guanyin 100 sticks" (观音一百签) commonly used in Taiwanese temples; the two are not mixed.

| Code | Source | Type | Notes |
| --- | --- | --- | --- |
| sy | Official site of Shuiyue Gong temple, Bukit Rambai, Malaysia (`shuiyuegong.com.my`, sticks 1–100) | Published by a temple | All 100 sticks; many typos (庞娟, 孙滨, 摔壁归赵, etc.) |
| 51 | 51chouqian.com, Guanyin Lingqian 1–100 | Website | All 100 sticks; a few bracketed annotations removed |
| 72 | 72ju.net, Guanyin Lingqian 1–100 | Website | The "卦解" and "解曰" labels are swapped and were realigned by content; poems of sticks 6, 15, 38 and 85 have missing characters and are not counted for those sticks |
| zy | m.zhouyi.cc (易安居), Guanyin Lingqian 1–100 | Website | No story titles; some interpretations run into the following text, and overly long values are not counted |
| tw | Taiwan temples.tw "观音一百签" (`temples.tw/stick/fs_yin100`) | Common temple edition | A different text, used only as a reference: when a line differs by a few characters between versions, it helps decide which character is right; it never casts a vote |

The plain-language explanations in 51 and zy are identical and probably share an origin, so vote counts alone are not decisive.

## Selection rules

1. The four mainland sources are compared field by field (rank, palace, story title, the four poem lines, meaning, interpretation). Punctuation is stripped and a few variant characters are unified first (坭/泥, 啣/衔, and 已/巳, 戍/戌 in palace names).
2. Where all sources agree, the text is taken as is.
3. Where they differ, the majority wins by default. The majority is overridden in favour of a reading that is attested in some source and makes sense when:
   - the majority reading is an obvious homophone or look-alike typo, e.g. 凡笼/樊笼, 书饼/画饼, 白涕汤/白沸汤, 无暇/无瑕;
   - the majority reading breaks the rhyme, or breaks the four-character pattern of the interpretation;
   - the majority reading contradicts the stick's meaning or interpretation.
4. Only existing readings are chosen; no wording is invented.
5. Character usage is unified: 扳 (pān) is written 攀, 番 in the sense of "turn over" is written 翻, and 份 is written 分 (安分, 本分, 福分).
6. Where all mainland sources agree but the text does not make sense, the circulated text is kept and an editorial note (校注) with the Taiwanese reading is added to the stick. There are two such cases: "铜鸟居" in stick 6 and "成鹿箭" in stick 11.
7. Only story titles are kept (e.g. "钟离成道"). The story narratives circulating online are of unclear origin and contain obvious historical errors (for example, claiming Zhongli Quan lived in the Eastern Han under Emperor Wu of Han), so they are not included.

After revision the rank distribution is 23 upper, 59 middle and 18 lower. This differs slightly from the "22 / 60 / 18" often quoted online; the stick-by-stick comparison is taken as authoritative.

## Change table

The list of every place where the majority was overridden or character usage was unified (57 entries) is in the [Chinese version](校订记录.md#改动明细). It is generated automatically by `make_final.py`, and since each entry is about individual Chinese characters, it is not duplicated here.

## Regenerating

After changing the choices (`decisions.py`) or the page template (`template.html`), run the following in this directory (Python 3.8+, standard library only, nothing to install):

```bash
python -I compare.py 1 100      # compare the four sources, print a per-stick table, write consensus.json
python -I make_final.py         # apply decisions.py, write final.json, update the change table in 校订记录.md
python -I build.py              # validate the data and write the texts into ../index.html
```

`make_final.py` updates the change table only in the Chinese file; this English file has no table and needs no update.

`sources.json` holds the parsed text of each source. To re-scrape the pages, run `fetch.py` and then `parse.py`. Note: before fetching, download the zhouyi.cc index page to `raw/zy_list.html`; the Taiwanese edition also needs `temples_yin100.html` downloaded separately.
