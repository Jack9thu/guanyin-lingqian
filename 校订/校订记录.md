## 来源

用的是大陆流传最广的那一版《观音灵签》：第一签「钟离成道」，每签有吉凶、宫位、典故名、诗曰、诗意、解曰。这一版和台湾寺庙常用的「观音一百签」是两套不同的文本，不混用。

## 取舍规则

1. 四个大陆来源逐字段比对（吉凶、宫位、典故、四句签诗、诗意、解曰）。比对前去掉标点，并统一几个异体字（坭/泥、啣/衔，宫位里的已/巳、戍/戌）。
2. 各源一致的，照录。
3. 不一致的，先按多数取。下面几种情况不按多数，改用「有来源支持、且讲得通」的写法：
   - 多数一方是明显的同音、形近错字，比如凡笼/樊笼、书饼/画饼、白涕汤/白沸汤、无暇/无瑕；
   - 多数一方失韵，或者破了解曰的四字句式；
   - 多数一方和本签诗意、解曰对不上。
4. 只在已有的写法里挑，不自己造字句。
5. 统一用字：扳(pān)作攀，作翻转讲的「番」作翻，「份」作「分」（安分、本分、福分）。
6. 各大陆来源都一样、但讲不通的地方，保留流传本原文，在签上加「校注」，附上台湾本的写法。目前有两处：第 6 签「铜鸟居」，第 11 签「成鹿箭」。
7. 典故只取名字（如「钟离成道」）。网上流传的典故故事来历不明，有明显的史实错误（比如说钟离权是东汉人、生活在汉武帝时），所以不收。

校订后，吉凶分布为上签 23、中签 59、下签 18。网上常说的「上 22、中 60、下 18」和这个略有出入，以逐签比对的结果为准。

## 重新生成

改了取舍（`decisions.py`），或者改了页面模板（`template.html`）之后，在本目录依次运行（Python 3.8 以上，只用标准库，不用装包）：

```bash
python -I compare.py 1 100      # 比对四个来源，输出逐签比对表，写 consensus.json
python -I make_final.py         # 叠加 decisions.py 的取舍，写 final.json，并更新本文件的改动明细
python -I build.py              # 校验数据，把签文写进 ../index.html
```

`make_final.py` 只更新本文件（中文版）里的改动明细表；英文版 `校订记录.en.md` 不含这张表，不用跟着改。

`sources.json` 是解析好的各来源原文。要重新抓取网页，先运行 `fetch.py`，再运行 `parse.py`。注意：抓取前要先下载 zhouyi.cc 的目录页 `raw/zy_list.html`；台湾本还要另外下载 `temples_yin100.html`。
