# 观音灵签

**中文** | [English](README.en.md)

观音灵签一百签的抽签网页：摇签筒、掷筊问神、看签诗和解签。单个 HTML 文件，不依赖任何外部资源，手机、电脑都能用。

**在线使用：<https://jack9thu.github.io/guanyin-lingqian/>**

也可以下载 `index.html`，双击用浏览器打开，离线也能用。

> 传统民俗文化，仅供娱乐参考。

## 怎么玩

页面顶部可以在两个板块之间切换：

| 板块 | 要掷几次 | 次数限制 |
| --- | --- | --- |
| 每日运势 | 掷得 1 次圣杯就算数 | 页面开着期间只能求一签，关掉标签页后清除 |
| 运势抽签 | 连续 3 次圣杯才算数 | 不限次数，一事一签，签成后可以「另问一事」 |

流程两个板块一样：

1. 默念所问之事，点签筒或「诚心求签」。签筒摇约 1.7 秒，一支签落在签筒旁边。
2. 掷筊问神，每次点「掷筊」掷一次，直到掷满本板块要求的圣杯（一平一凸）。
3. 中途掷出笑杯（两平）或阴杯（两凸），这支签不作数，点「重新求签」从头摇。
4. 签成后显示签卡：签号、吉凶（上签朱红、中签赭黄、下签灰）、宫位、典故名、竖排签诗、诗意、解曰。个别签还有一条「校注」。

摇签或掷筊的动画进行时不能切换板块，其他时候随时可切。两个板块各自保留进度：抽到一半、签成之后、掷失败之后切走再切回来，都原样还在。

## 规则和参数

- **每次掷筊**：圣杯 50%，笑杯 25%，阴杯 25%。要改就改 `校订/template.html` 脚本开头的 `P_SHENG`，失败的部分由笑杯、阴杯平分。
  - 每日运势一次求成的概率是 50%，平均约 2 轮。
  - 运势抽签要连掷三次圣杯，一次求成的概率是 12.5%，平均约 8 轮。
- **每日运势一签**：签成后，把当天日期和签号存进浏览器的 `sessionStorage`。刷新页面或切回这个板块，都直接显示这支签；关掉这个标签页，记录由浏览器自动清除，再打开可以重新求签。过了零点也会失效。掷筊没成功时什么都不存。旧版本存在 `localStorage` 里的长期记录，打开页面时会自动清掉。
- 运势抽签的结果只在本次打开页面期间保留（切换板块不会丢），刷新或关掉页面后回到初始状态。
- 页面会记住上次停留在哪个板块（存在 `localStorage`，只是偏好，不含抽签结果）。
- 每日运势签成后，页面底部会出现「清除今日记录」，不用关页面也能清掉这次的记录（测试用）。
- 浏览器禁用存储时（比如部分无痕模式），照样能抽签，只是每日运势不锁定。
- 签号和掷筊结果用 `crypto.getRandomValues` 生成。
- 所有数据只存在你自己的浏览器里，页面不联网、不上传任何东西。

## 签文

用的是大陆流传最广的那一版《观音灵签》（第一签「钟离成道」）。签文从 4 个来源（一个寺庙官网、三个网站）逐字比对整理而来，并参考台湾通行本，改正了五十多处错字。只收典故名，不收来历不明的典故故事。吉凶分布为上签 23、中签 59、下签 18。

来源、取舍规则和每一处改动，都写在 [`校订/校订记录.md`](校订/校订记录.md) 里。

## 文件

```
guanyin-lingqian/
├── index.html         成品，单文件，签文数据内嵌在脚本里（也是 GitHub Pages 的首页）
├── LICENSE            MIT
└── 校订/              签文的比对和生成工具（Python 3.8+，只用标准库）
    ├── 校订记录.md     来源、取舍规则、改动明细
    ├── sources.json    各来源解析后的原文
    ├── decisions.py    人工取舍和校注
    ├── fetch.py / parse.py / compare.py / make_final.py / build.py
    ├── template.html   页面模板，build.py 把签文填进去生成成品
    ├── favicon.svg     浏览器图标源文件（朱红印章 + 楷体「签」，字形已转成路径），已内嵌进模板的 <head>
    └── consensus.json / final.json   中间结果
```

想改页面样式或逻辑，就改 `校订/template.html`，再在 `校订/` 目录运行 `python -I build.py` 重新生成 `index.html`（完整步骤见校订记录）。直接改 `index.html` 也可以，但下次重新生成时会被覆盖。
